# Definition of Done: Library.Lending

Tick a box only if it is true. An open box needs "left out:" and a reason.

- [x] tests-changed: a test file changed together with the code
- [x] tests-pass: all tests ran; none failed, none skipped
- [x] changelog: a line under ## [Unreleased]
- [x] no-todo: no TODO in the added lines
- [x] reviewed: a second person read the diff
